**Goal:** Resolve issue #4 by listing ACT rules for each success criterion alongside its axe-core rules, not listing test cases.

**Architecture:** Download W3C's `wcag-mapping.json` rule catalogue and normalize it into a compact checked-in snapshot. Enrich shared criterion data with matching rules, then render a section using the existing axe-core list styling. No network requests during builds or visits.

**Tech Stack:** Astro, Svelte, TypeScript, Node.js, Vitest, Playwright; no new dependencies.

**Spec:** User's description in this conversation: “similar to axe core summary details there should be another one with act rules for that sc”; “a list of act rules not test cases.”

## Review Focus

- Repeated approved/proposed versions: each rule appears once per SC, with the approved link preferred.
- Multi-criterion and secondary relationships: retain all source associations without including ARIA-only rules.

- Unsafe/malformed downloads: fail before overwriting the existing snapshot.
- No JavaScript, keyboard use, and narrow screens: ACT links remain readable and accessible.
